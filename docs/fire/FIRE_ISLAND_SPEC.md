## A. 先讀這頁：火島究竟在說什麼？

### 故事核心

水島的旅途中，一名從火島逃來的居民昏倒，斷斷續續說起家鄉近日的**不尋常黑煙和巨響**。玩家因此乘船前往火島調查。抵達港口後，玩家認識火山蜥蜴嚮導**洛洛（Lolo）**；洛洛也注意到異常，卻不知道原因，決定陪玩家尋找答案。

沿途，玩家發現農田受損，米斯和魯莫談起一隻被懷疑的岩石巨怪。兩人起初也受傳聞影響，卻在看到巨怪精心堆砌的村莊模型後，發現先前的判斷不公平。與後來得到名字「咚咚」的巨怪澄清後，他們順著不尋常的金屬碎片找到隱藏的基地，發現真正原因是發明家**伊格尼（Igni）**秘密測試飛往火星的火箭。

伊格尼停止試驗、開始清理農田，並與玩家及洛洛搭礦車回村道歉；但未察覺的冷卻系統故障突然引發危機。曾躲避人群的長者**奧提斯（Otis）**主動借出祖傳傳送門，讓村民趕回基地。伊格尼終於明白不能只靠自己，眾人合作修復設備，解除危機，最後在**安全且居民自願協助**的前提下，完成火箭發射。

**主題不是「壞人被打倒」**，而是：傳聞不等於事實；犯錯要停止傷害並承擔；情緒升高可以冷靜、求助；大家各有長處，一起合作才能完成夢想。

## B. 角色故事設定：每個人為什麼會出現在旅程中？

**三位角色正式命名（V1.2）**：農田受害者**米斯（Mis）**；傳聞擴大者**魯莫（Rumo）**；沉默岩石巨怪**咚咚（Dongdong）**。這些名字取代過往工作用稱呼「農夫A／農夫B／岩石巨怪」。其中「咚咚」是劇情中第55格才由洛洛提出的名字；第55格之前玩家不應知道。

### 1. 洛洛 Lolo｜從第1格開始陪伴玩家的火山蜥蜴

- **身分**：火島本地居民、探險嚮導；不是玩家選用的棋子。
- **外觀**：深灰火山岩色身體、橘金岩漿紋、護目鏡、小背包，可愛圓潤的2.5D黏土玩具風；正式造型以最新核准素材為準。
- **性格**：好奇、機靈、熱心、勇敢，偶爾衝動；並非從一開始就知道所有答案的「解說機器」。
- **首次登場**：**第1格，港口岩石上，拿望遠鏡看火山**。玩家聽見牠自言自語「奇怪……今天又冒黑煙了！」，由此搭話；洛洛聽聞水島居民的警告，主動自稱火島的嚮導，邀玩家一起調查。
- **一路參與**：和玩家走過村莊、農園、峭壁；在咚咚事件中也會犯下先入為主的錯，願意向咚咚道歉；與咚咚和玩家一起進基地；和伊格尼、玩家搭礦車回村；最後在搶修時處理高處排氣口。
- **角色弧線**：從「急著知道答案」變成「會聽、會觀察、會承認自己看錯」。

**可用的洛洛台詞方向（例句，非唯一逐字定稿）**

- 港口：「奇怪……今天又冒黑煙了！」
- 自我介紹：「我是洛洛，火島最厲害的嚮導！……嗯，至少我很熟這裡啦！」
- 聽聞水島居民的事：「連水島都有人聽見怪聲？那我們更得去看看了！」
- 巨怪真相前：「等等……那個碎塊，好像不像一般石頭。」
- 道歉：「對不起，我們只聽了傳聞，就誤會你了。」
- 搶修時：「上面的排氣孔交給我，我爬得上去！」

### 2. 奧提斯 Otis｜兩次露面，但前後意義不同

- **第5格**：只是怕與人接觸、迅速關門的獨居老人；不製造神秘感，不暗示祖傳器物。
- **危機時**：看到大家為家園著急、卻無法把設備和人員及時送到高處，終於自行決定借出家後的祖傳傳送門。
- **內心原因**：擔心祖傳寶物被拿走、損壞；不應寫成自私的壞人。
- **後續**：為大家打開通道已經是重大幫助，**不加入火箭修理工作**。

### 3. 米斯（Mis）｜受損農園的農夫，名字呼應誤判

- **名字寓意**：「米斯（Mis）」呼應英文 *mistake*（犯錯／誤判）及 *misunderstanding*（誤會）的 *mis-*；是角色創作名，並非英文單字的標準翻譯。
- 受黑色碎塊落入田裡、異常黑煙與巨響影響；擔心自己的土地與生活，情緒合理。
- 熟悉農田灌溉、管線維護；危機時協助修復冷卻管線。
- 即使伊格尼道歉，依然可以生氣；協助救島不代表已放棄求償或追究。

### 4. 魯莫（Rumo）｜名字源自 rumor（謠言）的農夫

- **名字寓意**：「魯莫（Rumo）」由英文 *rumor*（謠言、傳聞）改編，象徵從不完整觀察到傳聞擴大的過程。
- **只看見巨怪在附近，不曾親眼見牠往農田扔石頭**；傳聞經轉述越傳越離譜，村民最後把巨怪趕到峭壁。
- 熟悉繩索、牽引、固定支架；危機時負責加固結構。
- 真相後，**須在基地當面對巨怪承認誤會與道歉**，不是只和玩家私下說兩句。

### 5. 咚咚（Dongdong）｜走路咚咚咚的岩石巨怪

- **名字由來**：牠體型龐大，每走一步都會發出「咚……咚……咚……」的腳步聲，因此被叫作「咚咚（Dongdong）」。正式劇情在**第55格澄清誤會並道歉之後**由洛洛提出名字；之前角色對白仍稱「岩石巨怪」，不提前叫出名字。
- 完全不能說話；只能用低吼、動作、搖頭、石塊與模型表意。
- 堆的不是武器，而是整座村子的石頭縮影：屋子、居民、葉片田地、兩位戴草帽的農夫；牠自己小小地被放在很遠處，表示希望與大家一起生活卻遭排斥。
- 願意在玩家道歉後帶路，幫忙找金屬碎片與隱藏基地；留在基地等待眾人，之後支撐巨型設備。
- **不能把牠演成攻擊玩家的頭目，也不能用語音／字幕代替牠說話。**

### 6. 伊格尼 Igni｜有火星夢想、卻把事情搞砸的發明家

- 橘紅色火系角色，脾氣急，怕失敗被嘲笑，因此把火箭計畫藏在火山基地獨自進行。
- 秘密測試造成巨響、黑煙與金屬碎片散落，實際傷害農園、讓咚咚背黑鍋。
- 遇到挫折易發火，但能學會停下、冷靜、重想方法與求助。
- **責任順序必須完整**：知道傷害 → 停止測試 → 清理部分碎片 → 親自下山道歉、承諾後續恢復和補償 → 危機時優先保護島民 → 合作搶修 → 經安全確認才發射。
- 火箭發射是夢想的實現，不是對過去損害的自動赦免。

## C. 從第1格到第100格：完整連續故事分鏡

> **讀法**：以下依「玩家實際經歷的時間順序」撰寫，告訴 CODE 每一段**上一段帶來什麼線索、這一段發生什麼、接下來為什麼要往前走**。格號區間內的景色與串場是**連續氛圍**，不代表每一格都要跳出對話。六個強制主線錨點仍為 **5、30、55、80、90、100**；**第1格屬「進島開場」一次性劇情，不新增第七個主線錨點格**。

### 序章｜水島結尾 → 火島港口（火島第1格之前）【已確定前情】

**場景**：水島。來自火島的居民逃離家園、昏倒，被發現後斷斷續續說出：「火山最近常常發出奇怪的聲音……還有黑煙……」。

- 玩家得知這不是尋常的火山景觀，選擇出發調查。
- **不提前讓逃來的居民知道伊格尼或火箭計畫**；此時大家只有對異常的恐懼。
- 畫面轉至火島海岸、港口和遠方冒煙的火山。

**推進理由**：水島帶來了求助與疑問，玩家因此主動來到火島，不是毫無緣由被傳送到新地圖。

### 第一章｜第1格：港口岩石上的洛洛【必要開場】

**畫面**：黑色火山沙灘、停靠的小船、帶海風的村落邊緣。遠方火山傳來低沉聲響，一縷黑煙升上天空。港口大石上，一隻戴護目鏡、背小背包的火山蜥蜴正拿望遠鏡盯著火山。

**建議分鏡（1次短演出）**

1. 玩家上岸，抬頭看遠處的黑煙。
2. 鏡頭帶到岩石上的洛洛，牠放下望遠鏡，皺起眉頭。
3. 洛洛自言自語：「奇怪……今天又冒黑煙了！」
4. 玩家靠近，提起水島居民逃來、說火山常發怪聲的事。
5. 洛洛先驚訝，接著表明自己熟悉火島，願意當嚮導；牠**也不知道原因**。
6. 兩人約定先去村莊看看，再往農田與火山方向調查。

**示例對話（可微調）**

- 洛洛：「奇怪……今天又冒黑煙了！」
- 玩家：「我們從水島來。有個從這裡逃出去的人說，火山最近常發出怪聲。」
- 洛洛：「原來不只我覺得不對勁！我是洛洛，火島最厲害的嚮導！我帶你去村裡問問吧。」

**這段演出的目的**：正式介紹洛洛、建立共同目標、說明牠接下來為什麼一路同行；不可省略或改成不明原因直接跟隨。

### 第二章｜第2–4格：走進村莊，異象尚未有答案【串場】

**畫面**：港口小路接白牆屋舍、木門、村民走動，遠方火山仍可見。對話以**少量環境短句**為主，不新增必須點完的長對話。

- 洛洛帶玩家認識安全的居民區，兩人交換對火山黑煙與異響的疑問。
- 村莊表面仍有人正常生活，但大家會不時望向山頂；氣氛不是立刻末日災難。
- 兩人路過一棟門窗緊閉的屋子，洛洛還沒主動解釋屋主的秘密。

**推進理由**：港口的疑問引導玩家走入村落，第5格才能自然聽見兩人談火山的聲音。

### 第三章｜第5格：奧提斯只開了一道門縫【主線錨點】

**畫面**：兩人走過奧提斯家，繼續談論火山。原本緊閉的門忽然開了一條縫，一位長者悄悄探出頭；玩家一靠近，門「砰」地關上。

**示例對話**

- 玩家：「咦？剛剛是不是有人在看我們？」
- 洛洛：「奧提斯是個習慣獨處的長者，每次有人想跟他說話，他都會這樣躲回家裡。」
- 玩家：「原來如此。那我們繼續去看看吧。」

**嚴格禁止**：門後的亮光、古老鑰匙、奇怪機械聲、傳送門影子、祖傳寶物提示、洛洛若有所思的暗示。這時就只是遇見一位不愛社交的長者。

**推進理由**：小插曲過後，玩家繼續走訪火島；奧提斯此時尚未和調查產生關聯，卻讓玩家記住這個人。

### 第四章｜第6–20格：離開村莊，朝山坡農園前進【旅途過渡】

**畫面**：白牆屋舍漸少，石階與小徑帶向山坡，能看到葡萄藤、橄欖樹和依山而建的農田。遠方偶爾傳來沉悶響聲。

- 玩家和洛洛從村莊外緣逐漸靠近農地；洛洛原先想帶玩家從各處觀察火山。
- **可以安排短促的景物反應，但不搶先講出農夫的全部證詞，也不揭露伊格尼**。
- 讓環境由溫暖日常慢慢轉成「這裡似乎受到異常影響」。

**推進理由**：想知道黑煙和怪聲是否真的造成損害，兩人前往最靠近山坡、最容易看到狀況的農田。

### 第五章｜第21–29格：農田的不安逐漸具體【旅途過渡】

**畫面**：田埂、灌溉管、零散燒焦痕跡、農作物和工具。這裡的景物顯示有人辛苦維護的土地受到外來物影響。

- 洛洛發現大家對火山的談論變得更焦慮。
- 玩家注意田地裡有奇怪碎塊的跡象，但正式**拾取、辨識與記錄證據**安排在第30格。
- 不讓任何路人先下結論說「巨怪確定扔石頭」或「一定是火箭」。

**推進理由**：兩人決定向真正受影響的農夫問個清楚，而不是只聽流言。

### 第六章｜第30格：米斯、魯莫、損壞的農田與傳聞【主線錨點】

**畫面**：一塊受損農田旁，米斯與魯莫正在討論近日黑煙、巨響和掉進田地的異常黑色塊狀物。

**表演順序不可顛倒**

1. **米斯說事實**：黑煙與聲響讓人不安，農田裡真的掉了奇怪的硬塊、弄壞部分作物或農地。
2. **魯莫說自己看見的事**：他曾在附近看過岩石巨怪，**但沒看見巨怪丟任何東西**。
3. 談到村民轉述的謠言愈傳愈誇張，最後大家認為是巨怪惹禍，把牠趕到峭壁。
4. 玩家在田間找到一塊奇怪黑色碎塊：**邊緣平直、似經加工，與自然石頭不太一樣**；玩家先收好，不立刻下定論。
5. 洛洛提議往峭壁找到岩石巨怪，至少應問清楚，而不是只憑傳聞。

**對話示例（可調整、但事實必須保持）**

- 米斯：「田裡真的被掉下來的東西砸壞了！這樣下去，我們怎麼種田？」
- 魯莫：「我有在附近看過岩石巨怪……可是，我沒有親眼看到牠扔石頭。」
- 洛洛：「大家都說是牠，可是……我們還是去找牠問問吧。」
