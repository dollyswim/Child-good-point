# 手機實機驗收清單

> 版本 `2026.11.08-68`｜2026-11-07 更新｜在 Android 手機上照順序勾選。
> 自動測試（模擬手機 360／390／430px）已全部通過；這份清單是確認**真的手機、安裝到主畫面的 App** 也正常。

## 0. 開始前（一定要做）
- [ ] ⚙️ 設定 → 備份 → **匯出 JSON**，先把現在的資料存一份
- [ ] 設定 → 備份 → App 版本顯示 `2026.11.08-68`（不是的話：關掉 App 再開一次；還不是就到瀏覽器重新整理）
- [ ] 小孩頁面右上角（設定城堡下方）→「新增孩子」→ 新增一位「測試」孩子，下面的冒險測試都用他，不影響真的孩子

## 1. 基本功能
- [ ] 首頁、小孩、挑戰、兌換、紀錄五個分頁可以切換
- [ ] 機器貓（左上）回首頁；城堡（右上）進設定，要輸入家長密碼
- [ ] 替「測試」記一筆加分、再撤銷，點數正確

## 2. 進入冒險與結算
- [ ] 替「測試」記一筆大加分（例如在設定新增「測試加分 1000 分」）→ 任務頁「進入今日冒險」→ 拿到能量星星（1000 分＝200 星）
- [ ] 再記一筆 20 分 → 設定 → 孩子 →「重新結算今天」→ 顯示補發 ⭐4 → 補發後星星正確
- [ ] 再按一次「重新結算今天」→ 顯示沒有要補發的星星

## 3. 金島地圖（第 1～100 格）
- [ ] 地圖顯示四區背景，接縫看不出線；可以拖曳、雙指縮放、🎯 回到角色
- [ ] 商店買 6 面骰 → 擲骰 → 角色逐格移動，停在格子正中間
- [ ] 重新整理（或關掉 App 再開）→ 角色位置不變
- [ ] 商店買「任意門」→ 點地圖上第 97 格傳送過去（任意門每天只能用 1 次；溜冰鞋＋飛行翼合計每天 5 次，用完按鈕會變灰）
- [ ] 擲骰（點數不夠就再擲；擲超過也會停在第 100 格）→ 走到第 100 格（城堡門前）停下 → 門前放煙火彩帶 → 出現全螢幕「恭喜通關金島！」→ 拿到神秘寶箱 ×1
- [ ] 地圖下方提示「已抵達金冠城堡、通關金島！」；圖例顯示「全島終點」
- [ ] 下一次擲骰從起點開始新的一輪

## 4. 成就
- [ ] 首頁「最近得到的成就」顯示「測試」最近 3 個；點那一列 → 小孩頁面自動展開「全部成就」（已解鎖 N / 23，冒險綠框、收集紫框、生活金框）
- [ ] 「測試」應該已解鎖：冒險開始、抵達水晶礦谷、抵達齒輪工坊、抵達金冠城堡、金島通關、獲得 1000 分
- [ ] 點任一個成就可以看到說明與達成日期
- [ ] 得到新成就時出現「成就解鎖！」全螢幕演出（有音效，右上角 🔊 可關）；一次得到多個會顯示「哇！一次解鎖 N 個成就！」；手機轉橫也看得到按鈕；按返回鍵只會關掉演出
- [ ] 替「測試」勾選完成一個特殊任務 → 得到「第一個特殊任務」→ 按「撤銷上一筆」→ 跳出提醒「會一起收回成就」→ 撤銷後成就消失

## 5. 小遊戲與其他
- [ ] 停在小遊戲格 → 「抓住星星」可以玩、星星正確
- [ ] 「結束今日冒險」→ 今日小結 → 當天鎖住；設定 →「解除今天的結束」可以解開

## 6. 離線與安裝
- [ ] 從主畫面圖示開啟 App（不是瀏覽器分頁）一切正常
- [ ] 開飛航模式 → 開啟 App → 首頁、地圖背景都能顯示

## 7. 結束
- [ ] 設定 → 孩子 → 刪除「測試」孩子
- [ ] 真的孩子的點數、星星、位置都沒變
