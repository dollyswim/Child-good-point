# 金島支線「齒輪小屋：吃飯好行為大挑戰」計畫初稿

> 版本：初稿 v0.1（2026-11-19）｜依據：家長企劃書 V1.0
> 狀態：**A 階段完成（2026-11-19，版本 2026.11.19-227）**：程式＋表情符號暫代圖、`#gear-test` 試玩、單元與 E2E 測試。下一步 B 階段：家長產圖（`docs/art-prompts.md` H-1～H-12）。

## 1. 評估結論

企劃書可以在現行架構下做，不需要改架構，也不會動到 100 格路線、擲骰、能量星星和生活點數。

| 項目 | 評估 |
|---|---|
| 入口 | 可行。第二區左上那塊空草地（長地圖座標約 x 120～390、y 2750～2945）緊鄰第 53～56 格，放一間小屋剛好。做法跟能源主塔、阿翔一樣：地圖上放一張圖，點了就開視窗。 |
| 玩法 | 可行。用現有的全螢幕視窗（跟撈魚、落葉找松果一樣蓋住整個畫面），裡面只有「換圖＋按鈕」，沒有複雜動畫，手機負擔很小。 |
| 題庫資料化 | 可行。6 種行為寫成一張資料表（台詞、圖檔、後果、正確提醒），以後調整情境只改這張表。 |
| 程式位置 | 比照水島，新開獨立檔 `js/gear-house.js`，不再讓 `js/app.js` 變大。 |
| 美術 | **最大的工作量**。照企劃書的清單大約 22 張圖，第 5 節建議縮減成 13～15 張。圖到之前可以先用表情符號和文字暫代，先驗收流程。 |
| 試玩 | 加 `#gear-test` 試玩網址（跟 `#fish-test` 一樣），家長不用走到小屋也能測。 |

## 2. 需要調整或補充的地方

1. **「金島小英雄」和「不影響主線」衝突**
   企劃書說這是獨立支線、不影響主線，但先前你選了「金島小英雄改成要做 4 個任務」。兩者只能選一個，見第 7 節第 1 題。

2. **嗆咳情境要有大人在場**
   企劃書寫「附近大人立即前來查看」，但這時媽媽已經出門，現場只有玩家和小齒。建議改成：小齒一咳嗽，媽媽剛好回到門口，聽到後馬上跑過來查看。這樣孩子看到的是「大人會來幫忙」，不是「小孩自己處理」。見第 7 節第 2 題。

3. **12 秒和「沒有倒數壓力」不衝突**
   畫面上不顯示倒數，12 秒只是程式內部的計時，到了就自動播後果。

4. **一局 3 題怎麼抽**
   每局從 6 種行為隨機抽 3 種，同一局不重複。建議「屁股坐」不要每局都出現，但連玩 2～3 局內一定會碰到（避免它太少見）。

5. **選錯時的提示**
   選錯不扣分，用溫和的一句話引導，例如「小齒的眼睛有在看飯嗎？再看看他在做什麼。」每種行為準備一句引導，寫在題庫裡。

6. **什麼時候可以進小屋**
   建議：孩子在金島走到第 53 格以後，小屋才會亮起來可以點（之前是一間沒開門的小屋）。這樣故事上是「經過小屋」，也不會讓剛開始玩的孩子一出發就被吸走。見第 7 節第 3 題。

7. **每天可玩幾次**
   企劃書沒有獎勵，重玩不會影響星星，所以建議不限次數。如果之後要給獎勵，再改成每天 1 次。

## 3. 遊戲流程（程式邏輯）

```
點小屋
 └─ 開場對話（媽媽半身圖＋下方對話框，沿用 talkPortrait）
     媽媽：「我得去工坊拿個東西，可以幫我陪小齒吃飯嗎？」→［好啊！］
 └─ 進入餐廳（固定場景）
     頂部：齒輪小屋・1/3
     中央：小齒吃飯圖
     下方：一句台詞／行為提示
     底部：6 個好行為按鈕（2 欄 × 3 列，平常就能按）
 └─ 每一題：
     1. 正常吃飯 2～3 秒
     2. 換成問題行為圖＋台詞（例：「我想玩小車車！」）
     3. 玩家按按鈕：
        - 選對 → 小齒改正（開心圖＋台詞）→ 下一題
        - 選錯 → 溫和提示，可以再選
     4. 12 秒都沒選對 → 播一次後果（換後果圖＋說明），之後仍可選正確提醒
        （同一題的後果只播一次，不累積其他事件）
 └─ 3 題完成 → 媽媽回來
     媽媽：「謝謝你陪小齒吃飯！你真是個好幫手！」
     「挑戰完成」＋［回到金島］
```

- 按鈕平常就可以按。還沒出現問題行為時按了，就顯示「小齒現在吃得很好喔！等等看他有沒有需要提醒的地方。」不算錯。
- 中途可以按左上角「離開」，不存進度，下次重新開始。

### 屁股坐（安全情境）

| 階段 | 畫面 | 台詞／說明 |
|---|---|---|
| 1 正常 | 小齒坐著吃，旁邊有小車車 | 小齒：「我想玩小車車！」 |
| 2 問題 | 小齒拿著食物站起來走向玩具 | （等玩家提醒） |
| 3 後果 | 小齒停下來咳嗽，表情驚嚇；媽媽回到門口跑過來 | 「小齒邊走邊吃，被食物嗆到了！還好他用力咳嗽，把食物咳出來了。」 |
| 4 改正 | 小齒回到椅子上，媽媽在旁邊 | 小齒：「原來邊走邊吃會有危險！我要坐好再吃！」 |

安全限制照企劃書：不表現催吐、不誇張窒息、不讓孩子操作急救、不當成好笑的事。第 3 階段只出現「有效咳嗽、恢復呼吸」，不出現「無法呼吸」。

## 4. 技術做法

### 新增檔案
| 檔案 | 內容 |
|---|---|
| `js/gear-house.js` | 題庫資料表、遊戲流程、畫面（`CGPGearHouse(A)`，比照 `js/water.js`） |
| `images/gold/gear-house/` | 小屋外觀、室內背景、小齒、媽媽、按鈕圖示 |
| `tests/gear-house.test.js` | 單元測試：抽題不重複、題庫 6 種都完整、計時規則 |
| E2E 一段 | 點小屋 → 完成 3 題 → 回金島；選錯可重選；12 秒後果只播一次 |

### 題庫資料表（範例）
```js
var MEAL_RULES = [
  { id: 'sit', label: '屁股坐', icon: '🪑',
    cue:   { img: 'walk.webp',  line: '我想玩小車車！' },
    hint:  '小齒現在坐在椅子上嗎？',
    after: { img: 'cough.webp', line: '小齒邊走邊吃，被食物嗆到了！…', mom: true },
    fixed: { img: 'happy.webp', line: '原來邊走邊吃會有危險！我要坐好再吃！' } },
  // …其餘 5 種
];
```

### 存檔
- 只加一個欄位 `p.gearHouse = { plays: 0, firstDone: null }`，在 `migrate()` 補預設值，用來記錄玩過幾次與第一次完成的日期（給成就或之後的獎勵用）。
- 不寫入星星、點數、紀錄，不影響每日上限。

### 地圖
- 小屋放在長地圖 (255, 2850) 附近（第二區草地中央），寬度約 180～200px，跟能源主塔同樣用 `z-index` 依 y 值排序。
- 點小屋時，如果角色正在走或有動畫（`pawn-acting`），先不開。
- 只在金島顯示。

### 快取（依 CLAUDE.md）
- `js/gear-house.js` 與小屋外觀圖加入 `sw.js` 的 `SHELL`。
- 室內與角色圖（約 10 張以上）**不放 SHELL**，第一次進小屋才下載並快取，免得每個孩子第一次開 App 都要多下載。孩子走到第 45 格左右時，在背景先下載（比照木島後段預先下載水島圖）。
- 升 `CACHE` 與 `APP_VERSION`。

## 7. 家長決定（2026-11-19）與修正

| 問題 | 決定 | 對計畫的影響 |
|---|---|---|
| 跟主線的關係 | **算進「金島小英雄」**（要完成 4 個任務） | 小屋變成金島第 4 個任務（代號 `meal`），加進 `STORIES`。「金島小英雄」改成 4 個任務都要做；已經拿到徽章的孩子保留（成就拿到就存檔）。金島「任務重置」也會一起重置小屋。 |
| 開放時機 | **走到第 53 格觸發任務** | 跟第 5、30 格一樣：這一擲**經過或停在**第 53 格就觸發（第 53 格原本的寶箱照常給）。孩子在對話時按「等一下」，小屋就留在地圖上發光，之後點小屋再進去。 |
| 每天次數 | **不限次數** | 第一次完成才給獎勵（見下方待決定）；之後點小屋可以一直重玩，不給星星。 |
| 嗆咳情境 | **玩家的角色來幫忙** | 改成孩子自己選的角色（`images/characters/`）跑到小齒旁邊陪他。細節見下方待決定。 |

### 第 2 節要跟著改的地方
- 第 2 節第 1 點（跟主線衝突）：已決定算進主線。
- 第 2 節第 2 點（大人在場）：改成玩家角色。
- 第 2 節第 6 點（什麼時候能進小屋）：已決定第 53 格觸發。
- 第 2 節第 7 點（每天次數）：已決定不限次數。

### 最後兩題（2026-11-19 家長決定）
1. **第一次完成給 ⭐3**，跟其他金島任務一樣（`completeStory`）。重玩不給；任務重置後再完成一次會再給。
2. **嗆咳情境：自動演出，玩家角色去叫大人**。孩子不用操作：
   小齒停下來咳嗽 → 玩家角色跑到旁邊大喊「媽媽！小齒嗆到了！」→ 媽媽馬上跑回來，陪在小齒旁邊 →
   「小齒用力咳嗽，把食物咳出來了，呼吸恢復正常。」→ 之後仍要孩子按「屁股坐」才算完成這題。
   - 不演拍背、催吐；不出現「無法呼吸」。
   - 媽媽這次提早出現，演完留在旁邊，第 3 題結束時直接說結尾台詞。
   - 要多一張圖：玩家角色喊人的樣子不另畫，用孩子自己的角色圖（`images/characters/`）＋對話框。

### 美術清單調整
- 第 13 張媽媽半身：開場、嗆咳、結尾共用。
- 不需要另外畫大人或技師。

### 美術做法修正（2026-11-19，寫提示詞時）
- 餐廳改成「**同一個場景的整張圖**」：H-3 正常吃飯當基準，其他動作都用同一張圖改，程式只換圖、不用把角色疊在背景上對位置（比照第 30 格礦車的前後兩張圖）。所以不需要單獨的空背景圖。
- 圖：H-1 小屋外觀、H-2 媽媽、H-3 正常吃飯、H-4～H-9 六種問題、H-10 嗆咳、H-11 開心改正（必做 11 張）＋ H-12 手沾滿飯粒（選做）。提示詞在 `docs/art-prompts.md` 最後一節。
- 4 種後果（飯菜變涼、食物掉桌上、聊天沒吃、水杯倒了）由程式疊小圖示與文字。

### 每題只違反一條（2026-11-19 家長）
家長發現原本「玩玩具」同時也沒看飯、沒在吃、沒拿湯匙，好幾個答案都說得通。改成每題只有一個壞習慣，其他都做得好：
30分鐘吃完＝吃得慢吞吞（後果：窗外變黃昏、湯涼了）；眼睛看＝看窗外小鳥；嘴巴吃＝一直講話（後果改成飯粒掉衣服上）；用餐具＝用手抓；屁股坐＝站起來在餐桌旁走來走去吃（不去拿玩具）；腳放地上＝腳縮椅子上。
文字在 `js/game.js` 的 `MEAL_RULES`；美術 H-4 改成慢吞吞、新增 H-4b 黃昏（必做 12 張）。
