# 親子集點冒險：美術素材 AI 繪圖提示詞

> 目的：補齊 Phase 3 金島用到、目前以表情符號代替的圖示，畫風對齊「8 種冒險夥伴」與「金島主視覺」。

## 使用方式

1. **先上傳風格參考圖**：把「8 種冒險夥伴」角色設定圖當作風格參考（style reference／image prompt）一起上傳，畫風最容易統一。
2. 每張圖 = **共用風格** ＋ **主體描述**（英文版效果通常比較穩定，中文版供參考）。
3. 一張圖只畫一個物件、置中、不要文字。
4. 做不出透明背景沒關係，用**純白或純色背景**，傳給我後我幫你去背。
5. 同一批圖盡量在同一個對話／同一組設定中連續生成，畫風會更一致。
