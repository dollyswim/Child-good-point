## 4. 神諭祝福（媽媽加碼）

位置：⚙️ 設定 →「神諭祝福」分頁（整個設定受家長密碼保護）。孩子畫面上顯示「神諭祝福」。

| 獎勵 | 效果 |
|---|---|
| 📦 一般寶箱 | 加入寶箱庫存；開箱沿用一般寶箱內容（1～3 星、溜冰鞋、6 面骰） |
| 🎁 神秘寶箱 | 加入寶箱庫存；**不需要黃金鑰匙**，直接開；內容沿用神秘寶箱獎勵池 |
| 🎲 命運重骰券 | 對剛擲出、尚未前進的結果重擲一次，**用原本的骰子重擲**（6 面重擲 6 面、12 面重擲 12 面），以新結果取代；不額外占用每日次數；同一次結果只能用 1 張 |
| 🎮 再來 3 次 | 放進背包，孩子按「啟用」後，**今天**額外 +3 次擲骰、+3 次小遊戲（不受每日上限）；今天沒用完就失效，不跨日、不轉神秘寶箱 |
| 🌟 幸運星 | 立即 +10 能量星星（星星帳記「神諭祝福：幸運星」），不經結算、不被加倍 |

規則：
1. 只有輸入家長密碼才能發送；**資料寫入函式本身也檢查**（不是只隱藏按鈕）。
2. 選擇孩子、獎勵、數量（預設 1）、可選填鼓勵文字。
3. 不消耗生活點數與能量星星；不算進寶物商店每週 3 件。
4. 每次發送保存：時間、對象、獎勵、數量、鼓勵文字；設定頁顯示最近發送紀錄。
5. 孩子下次打開冒險大廳時，看到「神諭祝福」領取畫面（含鼓勵文字與簡短動畫）。

### 額外額度（再來 3 次）的計算
- 每日基本上限不變：擲骰 3 次、小遊戲 1 次。
- 額外額度另存（`adventure.bonusQuota`：孩子、日期、擲骰剩餘、小遊戲剩餘）。
- 基本次數用完後才扣額外額度。
- **額外的小遊戲**：當天小遊戲已玩過、又停在小遊戲格時，使用 1 次額外額度開始小遊戲（不產生神秘寶箱）。
- 「當次冒險」＝今天的冒險：從「進入今日冒險」到「結束今日冒險」或午夜；重新整理不會清除。

## 4-1. Phase 3 實作備註
- 家長密碼：`data.parentPin`（只存雜湊與鹽）；`store.setParentPin / unlockParent / lockParent / allowPinReset`；解鎖只存在記憶體，**離開設定或重新整理就上鎖**。忘記密碼：答對兩位數乘法題後重設。
- 神諭祝福：`store.sendBlessing(childId, kind, qty, message)`，寫入前 `_requireParent()` 檢查；紀錄 `data.adventure.blessings`；孩子進冒險大廳時 `showBlessings()` 顯示未看過的祝福。
- 寶箱庫存：背包 `chest`（一般寶箱）、`giftMysteryChest`（神諭祝福的神秘寶箱，免鑰匙）；`store.openChest()`；一般寶箱內容與地圖寶箱格共用 `_rollRegularChest()`；神秘寶箱 `_rollMysteryChest()`（機率 溜冰鞋、神奇骰子、好運金牌、防護罩各 18%，飛行翼、任意門各 12%，呼叫專機 4%）。
- 紀錄：`data.adventure.itemLog`（取得 grant、開箱 open；使用 use 於 Phase 4 加入）。

## 4-2. Phase 4A 實作備註（道具效果）
- **擲骰分兩步**：`prepareRoll()`（擲出點數、計入次數、存 `players[id].pendingRoll`）→ `commitRoll()`（前進、觸發事件）。沒有重骰券時 `rollDice()` 連續執行兩步。重新整理後地圖顯示「已擲出 N，點這裡繼續」。
- **擲骰紀錄種類** `rolls[].kind`：`base`（每日 3 次）、`bonus`（再來 3 次）、`magic`（神奇骰子）。`getRollsToday()` 只算 base。
- **命運重骰券** `rerollPending()`：用原骰子重擲、新結果取代、同一次只能 1 張、不增加次數。
- **神奇骰子**：12 面、不占每日 3 次、每天最多 1 顆（`magicUsedToday()`）。
- **再來 3 次** `activateBonusPlay()`：`adventure.bonusQuota` 今天 +3 擲骰、+3 小遊戲；基本次數用完才扣；隔天失效。額外小遊戲在停到小遊戲格時使用（`minigames[].bonus = true`）。
- **飛行翼** `useWings()`：前進 20 格、第 30 格停、落點觸發事件。**任意門** `useDoor(n)`：地圖點選格子（不含起點、目前位置、第 30 格），落點觸發事件。
- **好運金牌** `activateMedal()`：`players[id].medalArmed`；下一次寶箱開 2 次、機會卡抽 2 張。
- **防護罩**：命運卡「後退」時自動抵擋並消耗；路障沒有實際影響，不消耗。
- **呼叫專機**：顯示「其他島嶼開放後」，目前不能使用。
- 所有使用都記在 `itemLog`（action = use）。

## 4-3. Phase 4B 實作備註
- **地圖神秘寶箱** `adventure.mapChests`：`_addMapChest(source)` 先建立（未出現），`placeMapChests()` 在孩子當天出發後進入地圖時，放在這座島上角色還沒走到的格子（前方第 2 格到終點前一格隨機，兩個寶箱不同格；2026-11-09 家長調整，原本前方 2～8 格）；次數用完轉換的（overflow）要隔天才出現，**還沒撿走的總共最多 2 個**（跨天也算，撿走一個才能再轉；2026-11-09 家長調整，原本每天最多 2 個）；里程碑的下次進地圖就出現。
- 經過或停在該格（含後退經過、任意門落點）就撿到 → 背包 `mysteryChest`（要黃金鑰匙開）；沒撿到一直留著。進地圖提示「附近似乎藏著神秘寶物……」只顯示一次。
- **目前唯一的次數用完轉換來源**：今天小遊戲已玩過又停到小遊戲格（沒有「再來 3 次」額度時）。
- **黃金鑰匙**：星星商店 10 星；開 `mysteryChest` 消耗 1 把。神諭祝福的 `giftMysteryChest` 免鑰匙。
- **寶物磁鐵**：星星商店 10 星；`getMagnetTargets()` 前後 5 格內的地圖神秘寶箱與未被吸過的一般寶箱格；吸過的寶箱格記在 `players[id].looted`，再停上去沒有獎勵（也不消耗好運金牌）。
- **累計得分里程碑** `data.milestones[childId] = { base, keys, chests }`：base＝開始計算時的累計得分（舊存檔＝載入當下、新孩子＝起始點數）；每 +500 黃金鑰匙、每 +1000 地圖神秘寶箱；只增不減、不重複發。
- **機會卡** 5 種：礦車前進 2 格、發光礦石 +2 星、6 面骰、小寶箱 +1～3 星、溜冰鞋。

## 4-4. Phase 5 實作備註
- `store.endAdventure()`：記 `adventure.dayEnds`；`canPlayToday()` 改為「已結算且今天未結束」，所有遊戲動作都會被擋；擲骰結果還沒前進時不能結束。
- 結束時作廢今天的「再來 3 次」剩餘次數、未完成的小遊戲（status `expired`）；背包道具保留。
- `store.getDaySummary()`：從 `players[id].dayStart`（每天第一次移動前記錄）計算走了幾格，並彙整擲骰、星星帳、道具紀錄（寶箱格、機會卡給的道具也會記錄）、小遊戲、新特殊任務、神秘寶箱。
- 冒險大廳與任務頁顯示「今天的冒險已結束」，可再打開今日小結。

## 5. 家長密碼

- 第一次進入 ⚙️ 設定時設定 4 位數密碼；之後每次進入設定都要輸入。
- 忘記密碼：在設定入口提供「忘記密碼」說明（需匯出備份後清除，或由開發者協助）。
