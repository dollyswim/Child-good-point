## 4. 換島規則（程式已完成 2026-11-07；木島資料到貨後用 `registerBoard('wood', …)` 開放）
- 孩子**第一次通關金島**後，下一次出發移到木島起點；之後在木島繞圈，通關木島再前往水島（順序 金 → 木 → 水 → 火 → 土 → 金）。
- 木島還沒開放前，照現在一樣在金島繞下一輪。
- 金島的進度、成就、地圖寶箱都保留；背包道具跟著孩子走。
- 冒險大廳的關卡卡依孩子所在島嶼自動換圖（已有木島入口插圖 `images/islands/wood.*`）。
- 每座島的進度存在 `players[id].islands[島]`（laps、maxReached），金島以外的通關次數存 `islandClears`（`getPlayer()` 補預設值）。

## 5. 製作順序
1. **Codex 先交全島配置草圖**：4 區粗略構圖接在一起的總覽、第 1～100 格建議座標 JSON（家長確認路線與主題）。
2. 依序畫正式背景：第一區 → 第二區 → 第三區 → 第四區（每張要和下一張接縫，比照金島的接縫參考圖做法）。
3. 每區交件後 Claude 核對（尺寸、接縫、格子在路上、格距），通過就上線；未開放的區域用雲霧遮住。
