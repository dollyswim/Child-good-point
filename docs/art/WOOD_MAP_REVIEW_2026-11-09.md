# 木島地圖驗收（2026-11-09，Gemini 第 1 版）

驗收對象：全島長圖（400×2000 縮圖）、第 4 區原尺寸圖（1080×1350）、`wood_island_coordinates_0_100.json`。
驗收方式：把 JSON 的 101 格、小精靈站位、派對草地畫在地圖上比對（格子中心應落在畫好的路面上）。

## 通過的項目
- 101 格（0～100），相鄰格距 65.80～71.16px，符合 64～76px。
- 三條接縫（y = 4050、2700、1350）的**道路**左右緣與中心對齊，路面顏色銜接自然。
- 4 區的分區、小精靈任務格（8、40、65、92）、左下商店與右下縮放按鈕的保留區都有。
- 第 0～91 格大致都在路上。

## 需要重畫／修正的項目

### A. 缺原尺寸圖（必要）
只有第 4 區是 1080×1350，第 1～3 區只有全島縮圖（400×2000，約原尺寸 37%），放進 App 會模糊。
→ 請提供 `wood_region01`～`wood_region04` 四張，各 **1080×1350**（PNG 或高品質 WebP），四張上下拼起來就是 1080×5400 的全島。

### B. 接縫處兩側的樹木、草叢對不上（必要）
放大三條接縫看，只有路是對齊的，兩旁的景物是用**半透明羽化**硬疊上去：
- y = 4050（第 1→2 區）：右側上方是開花灌木，下方突然變成樹幹，中間有半透明疊影；左側紅花叢被淡化切掉。
- y = 2700（第 2→3 區）：右側樹枝與葉叢在接縫處糊成一片，看得到兩張圖重疊的殘影；左側蕨葉被切斷。
- y = 1350（第 3→4 區）：左右兩側的蕨類與樹叢被霧化，接縫上下的樹叢形狀、顏色、亮度不同。

要求：
1. 接縫不要用半透明羽化或霧化遮掩，不能有疊影、殘影或一條模糊帶。
2. 跨過接縫的樹幹、樹冠、灌木要**同一棵延續**：接縫上下的位置、粗細、顏色、亮度一致；或者乾脆讓接縫附近（上下各約 80px）只有草地和路，大型景物都完整畫在同一區內。
3. 接縫上下各 1px 的像素顏色應幾乎相同（整條橫線看不出分界）。

### C. 第 93～99 格不在路上（必要）
第 4 區的路從第 92 格往右上彎，經過草地中央接到巨樹拱門；但第 93～99 格沿著左邊的蘑菇、花叢和樹根往上排，**整段不在路面上**（第 96、97 格壓在蘑菇上，第 98、99 格壓在樹根上）。
→ 二擇一，並在回覆中說明採用哪一種：
- 重畫路，讓路從第 92 格沿著第 93～99 格現在的位置走到第 100 格的拱門；或
- 保留路，重新計算第 93～99 格座標，讓它們落在路中央，相鄰格距仍為 64～76px。

### D. 小精靈站位與派對草地壓到路或物件
- 第 92 格站位（x 315～395、y 735～855）左上角壓在路上 → 往右移到路旁的空草地，整個 80×120 框都不可碰到路。
- 第 65 格站位（x 435～515、y 2035～2155）裡有木棧道的欄杆柱 → 移到完全空的草地。
- 派對草地（x 420～720、y 575～775）左上部分壓在路上 → 改成完全不碰路的空地；若 C 改走左邊，就照新的路重新框。

### E. 其他小問題
- 第 27 格壓在紅色蘑菇右緣 → 蘑菇往左移或格子往路中央移。
- 第 50～52 格在吊橋左端到土路之間，縮圖上看偏離路面中央 → 拿到原尺寸圖後請確認格子中心在路上。
- JSON 第 8 格站位寫 `left-upper meadow`，實際在路的右上方 → 改成 `right-upper meadow`。

把 JSON 每一格畫成直徑 70px 的圓、每個站位畫成方框，疊在 1080×5400 全島圖上：
