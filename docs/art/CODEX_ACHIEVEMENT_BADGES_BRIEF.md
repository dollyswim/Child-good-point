# 成就徽章美術規格（給 Codex）

> 家長定稿：`docs/art/achievement_badges.csv`（2026-11-07）。共 25 張：24 個成就＋1 張「未解鎖」。英文版：`CODEX_ACHIEVEMENT_BADGES_BRIEF.en.md`。

## 共同規格
- 每張 1024×1024 PNG，**純白背景**，徽章置中，四周留約 8% 空白；程式會縮小成約 56px 顯示，造型要簡單、輪廓清楚。
- 風格：延續金島的明亮 Q 版 3D 遊戲圖示（和道具圖示、格子圖示同一系列），柔和光影、圓潤可愛，適合 5～10 歲孩子。
- 外型：圓形徽章，粗外框依類別上色——**冒險＝綠色、收集＝紫色、生活＝金色、未解鎖＝灰色**；徽章內放主圖案。同一類別的外框要完全一致。
- 不要文字、字母或數字；**唯一例外**是「獲得 N 分」10 張金牌要刻出「N 分」，請逐張確認數字正確、清楚好讀。
- 不要浮水印、簽名、外框以外的裝飾、陰影落在背景上的大片灰色。
- 檔名照下表 `badge_代號.png`，代號請勿修改。
