# 木島 V2：參考金島畫風重製

本版使用內建 image_gen 重繪，依提供的金島參考圖採用明亮飽和的立體遊戲插畫、細緻木紋、葉片、岩石、草地及一致暖光。四區分別為森林入口、藤蔓吊橋、樹屋村、精靈巨樹。美術及功能配置經本次自行檢視；這不是使用者已確認驗收的紀錄。

四張 PNG 都不包含格子、編號、角色、文字或 UI。來源單區影像為 1092 × 1440，交界局部重繪來源為 1536 × 1024；正式素材縮放整理為指定尺寸，未使用低解析全島試作放大交件。

`wood_island_coordinates_0_100.json` 包含 101 格，請與本版 PNG 一起替換，不要混用舊版 JSON。

- `x`、`y`：世界像素座標，以全島左上為原點，向右／向下遞增。
- `backgroundId`：對應 PNG 檔名，不含副檔名。
- `localX`、`localY`：該背景圖內的像素座標。
- `fairySpots`、`partyLawn`、`safeZones`：世界座標矩形，x/y 為左上角。
- 現有 App loader 的欄位命名及實際裝置效果未實測；本次交付為圖片與座標資產。

### 接縫像素說明

三處接縫皆位於同一段連續重繪影像內。已附 300% 檢視圖，可檢查道路、草紋及跨界樹冠。相鄰兩列的平均 RGB 通道差約為 8.97、9.32、6.32（0～255）；有紋理與葉片邊緣，因此不是逐像素完全相同。此數值與逐像素雜訊差異不能單獨判定有無接縫，最終以完整景物延續與放大目視檢查為準。

### 檢查方法

`wood_island_review.png` 疊加直徑 70px 的編號圓圈、粉紅色站位／草地框及藍色 UI 保留區。另有四張分區檢視圖。格距、格號、分區與尺寸由程式檢查；中心是否落在可行走表面、清空框內是否有物件及美術接縫由圖面檢視確認。

土路色彩篩檢曾標記 11 個橋面格點；逐一以 300% 局部圖覆核後，確認是木板接縫、木紋與釘子造成色彩門檻誤判，格點中心仍在橋面。原始篩檢結果與覆核說明記錄於 `validation.json`，不把色彩分類當作物件辨識。
