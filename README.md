# 親子集點（Child-good-point）

親子集點養成冒險 App。完整規格見 [PROJECT_SPEC.md](PROJECT_SPEC.md)。

目前進度：**Phase 1｜生活積分核心系統** ✅（含冒險島風格介面）

### 介面與功能
- 底部導覽列：首頁／任務／挑戰／兌換／紀錄；任務、挑戰、兌換會進入目前選定的孩子，頁面上方可切換
- 首頁：孩子卡片（頭銜、等級、總點數、今日得分）、四個大按鈕（先選孩子再進入）、本週目標進度
- 等級：依累積「賺到的加分」計算（Lv.2 = 100、Lv.3 = 300、Lv.5 = 1000…每級多 100），扣分與兌換不降級
- 本週挑戰：某條規則本週達成 N 次／天，或本週淨得分達 N 點；達成後領取獎勵（記成一筆加分）
- 記分總覽：日／週／月統計、規則排行、每日任務完成率、明細更正與補登

## 使用方式

純 HTML / CSS / JavaScript，不需要建置。

- 直接以瀏覽器開啟 `index.html` 即可使用。
- 或啟動本機伺服器（可啟用 PWA 離線與「加到主畫面」）：`npm start` 後開啟 http://localhost:8080
- 也可直接部署到 GitHub Pages 等靜態網站空間。

資料儲存在瀏覽器 `localStorage`（鍵名 `cgp-data`），可在「設定 → 備份」匯出／匯入 JSON。

## 專案結構

```
index.html            入口

tests/e2e.js          手機尺寸端對端測試（Playwright）
```

## 資料模型（schemaVersion 1）

- 總點數 = 起始點數 + 所有紀錄點數（不另存，避免不同步）
- 今日淨得分 = 今日加分 + 扣分 + 任務；**不含**起始點數與兌換獎勵
- 扣分、兌換以負數保存
- 任務完成狀態由紀錄推導，每個孩子各自獨立
- 未來修改資料模型時，遞增 `SCHEMA_VERSION` 並在 `migrate()` 加入遷移步驟

## 測試

```
npm test          # 單元測試

```

## 用 Excel／Google 試算表管理規則（CSV 匯入）

在電腦用試算表整理規則，存成 CSV，傳到手機後在「設定 → 備份 → 匯入規則表」匯入。
點數紀錄全部保留；有「規則ID」的規則會依 ID 更新，新規則會新增，檔案裡沒有的規則不會刪除。
UTF-8 與 Excel 中文版預設的 Big5 編碼都能讀取。

| 欄位 | 說明 |
|---|---|
| 規則ID | 選填但建議填（例如 R001），之後改名稱或分數才能正確更新 |
| 規則類型 | 加分／扣分 |
| 適用對象 | 兩位孩子／全部／競賽冠軍者，或孩子名稱（多位用、分隔），名稱要和 App 裡一樣 |
| 任務或行為 | 規則名稱 |
| 點數變動 | 數字、空白（0 點）或「自填」 |
| 計算頻率 | 每次／每餐 → 加分按鈕；其餘會設為「📋 每日任務」放在常用區：每天 → 每日；上學日、平日 → 平日；週末；每週 → 每週 1 次；每週3次；每週一三五；達成一次 → 單次任務 |
| 額外獎勵 | 「5個能量星星」記為額外星星（Phase 2 發放）；「另扣錢」會加註在名稱後 |

其他欄位（例如分類、達成條件）可以保留，匯入時會忽略。範例見 `tests/fixtures/sample-rules.csv`。
