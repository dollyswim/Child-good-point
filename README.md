# 親子集點（Child-good-point）

親子集點養成冒險 App。完整規格見 [PROJECT_SPEC.md](PROJECT_SPEC.md)。

目前進度：**Phase 1｜生活積分核心系統** ✅（含冒險島風格介面）、**Phase 2｜冒險解鎖與能量星星** ✅、**Phase 3｜最小可玩金島** ✅

### 金島第一區（黃金沙灘與初級礦場）
- 正式無格子背景 `images/gold/region01.webp`（1080×1350，JPG 備援）；第 1～30 格座標來自 `data/gold_region01_tiles.json`
- `js/board-gold.js` 由 JSON 產生：`python3 tools/gen_board.py data/gold_region01_tiles.json js/board-gold.js`（勿手改）
- 背景、格子、事件圖示、角色放在同一地圖容器（參考像素 1080×1350）並套用同一縮放；可拖曳、雙指縮放、＋／－／🎯置中，移動時鏡頭跟隨
- 位置以穩定格子 ID（例如 `gold-01-007`）保存；舊存檔的整數格號自動對應；起點為第 1 格前方沙灘
- 第 30 格（礦場木門）為暫時區域邊界：停下並提示第二區即將開放，多餘步數捨棄，不是全島通關
- 預留第二～四區（31～55、56～80、81～100 格）資料位置，尚未製作

### Phase 3：最小可玩金島
- 冒險大廳「開始冒險」→ 金島 2.5D 等角棋盤（30 格，路徑繞過礦洞、工廠、齒輪、金屬橋）
- 星星商店：6 面骰 5 星、12 面骰 10 星、溜冰鞋 4 星（前進 3 格）；買來的道具放背包，隔天仍保留
- 每天最多擲 3 次骰子（6 面、12 面都算；溜冰鞋不算）；當天要先「進入今日冒險」才能玩
- 棋子一格一格跳過去；停格事件：寶箱（1～3 星或道具）、機會（前進 2 格／得 2 星／得 6 面骰）、小遊戲格（占位）
- 走到第 30 格停在終點；地圖資料（js/game.js）可擴充為 100 格
- 3 種原創測試角色：機器人吉祥物、小鹿、小箱獸，每個孩子各自選擇
- 星星收支記在星星帳（data.adventure.ledger），與生活點數分開

### Phase 2：冒險解鎖與能量星星
- 孩子任務頁最上方：今日淨得分 > 0 才解鎖，否則顯示「🔒 今日冒險尚未解鎖」
- 按「進入今日冒險」時結算：能量星星 = ceil(今日淨得分 ÷ 5) ＋ 規則／挑戰上尚未發放的額外星星
- 同一孩子同一天只結算一次（重新整理、重新開啟、匯入重複資料都不會重複發放）；結算後當天再加分不再增加星星
- 沒結算的日子不補發；結算後才記的額外星星留到下次結算
- 冒險大廳：角色預留位置、星星餘額、今日冒險狀態、地圖入口占位、結算紀錄
- 能量星星與生活點數分開保存與顯示（生活點數金幣改印「點」字，⭐ 只代表能量星星）

### 介面與功能
- 底部導覽列：首頁／任務／挑戰／兌換／紀錄；任務、挑戰、兌換會進入目前選定的孩子，頁面上方可切換
- 首頁：孩子卡片（頭銜、等級、總點數、今日得分）、四個大按鈕（先選孩子再進入）、本週目標進度
- 等級：依「起始點數＋累計得分」計算（加分、每日任務累加，扣分抵銷，兌換獎勵不影響），每 1000 分升 1 級（Lv.1＝0～999、Lv.2＝1000～1999…）
- 本週挑戰：某條規則本週達成 N 次／天，或本週淨得分達 N 點；達成後領取獎勵（記成一筆加分）
- 記分總覽：日／週／月統計、規則排行、每日任務完成率、明細更正與補登

## 使用方式

純 HTML / CSS / JavaScript，不需要建置。

- 直接以瀏覽器開啟 `index.html` 即可使用。
- 或啟動本機伺服器（可啟用 PWA 離線與「加到主畫面」）：`npm start` 後開啟 http://localhost:8080
- 也可直接部署到 GitHub Pages 等靜態網站空間。

資料儲存在瀏覽器 `localStorage`（鍵名 `cgp-data`），可在「設定 → 備份」匯出／匯入 JSON。


## 資料模型（schemaVersion 1）

- 總點數 = 起始點數 + 所有紀錄點數（不另存，避免不同步）
- 今日淨得分 = 今日加分 + 扣分 + 任務；**不含**起始點數與兌換獎勵
- 扣分、兌換以負數保存
- 任務完成狀態由紀錄推導，每個孩子各自獨立
- 未來修改資料模型時，遞增 `SCHEMA_VERSION` 並在 `migrate()` 加入遷移步驟

## 用 Excel／Google 試算表管理規則（CSV 匯入）

在電腦用試算表整理規則，存成 CSV，傳到手機後在「設定 → 備份 → 匯入規則表」匯入。
點數紀錄全部保留；有「規則ID」的規則會依 ID 更新，新規則會新增，檔案裡沒有的規則不會刪除。
UTF-8 與 Excel 中文版預設的 Big5 編碼都能讀取。

| 欄位 | 說明 |
|---|---|
| 規則ID | 選填但建議填（例如 R001），之後改名稱或分數才能正確更新 |
| 規則類型 | 加分／扣分 |
| 適用對象 | 兩位孩子／全部／競賽冠軍者，或孩子名稱（多位用、分隔），名稱要和 App 裡一樣 |
| 任務或行為 | 規則名稱 |
| 點數變動 | 數字、空白（0 點）或「自填」 |
| 計算頻率 | 每次／每餐 → 加分按鈕；其餘會設為「📋 每日任務」放在常用區：每天 → 每日；上學日、平日 → 平日；週末；每週 → 每週 1 次；每週3次；每週一三五；達成一次 → 單次任務 |
| 額外獎勵 | 「5個能量星星」記為額外星星（Phase 2 發放）；「另扣錢」會加註在名稱後 |

其他欄位（例如分類、達成條件）可以保留，匯入時會忽略。範例見 `tests/fixtures/sample-rules.csv`。
